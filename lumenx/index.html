LUMENX

Sag deine Stiche an, bevor du deine Karten kennst.

Du siehst nur die Farben deiner Hand, nicht die Werte. Trotzdem musst du vorher sagen, wie viele Stiche du holst. Gelb sticht alles. Wer richtig tippt, punktet.

LumenX spielen Windows · Linux Stich ausprobieren

So läuft ein Spiel

Vier Schritte, zehn Stiche

1

Geben

60 Karten in fünf Farben mit den Werten 1 bis 12. Jeder bekommt zehn Stück, sortiert nach Farbe.

2

Tippen

Jeder sagt an, wie viele Stiche er holen wird. Dabei kennst du nur die Farben deiner Karten, nicht ihre Werte.

3

Stechen

Wer ausspielt, legt eine beliebige Karte. Alle anderen müssen die Farbe bedienen, wenn sie können. Die höchste Karte gewinnt, Gelb schlägt alles. Der Gewinner spielt den nächsten Stich aus.

4

Werten

Nach zehn Stichen gibt es Punkte für jeden Stich. Jeder Stich Abweichung vom Tipp kostet 5 Punkte. Ein Match hat vier Spiele.

Gelb ist Trumpf

Eine gelbe 1 schlägt eine rote 12. Gelb darfst du aber nur spielen, wenn du die ausgespielte Farbe nicht hast. Wird Gelb ausgespielt, gewinnt die höchste gelbe Karte.

5 Farben 1–12 Werte 10 Karten pro Hand 4 Spiele pro Match 3–6 Spieler, du gegen den Computer

Selbst ausprobieren

Wer gewinnt den Stich?

Drei Karten liegen auf dem Tisch, die erste wurde ausgespielt. Tipp auf die Karte, die den Stich holt.

Welche Karte gewinnt?

0richtig 0gespielt 0Serie
  • Die zuerst gelegte Karte bestimmt die Farbe.
  • Wer nicht bedienen kann, legt eine andere Farbe und verliert den Stich, außer mit Gelb.
  • Unter mehreren gelben Karten gewinnt die höchste.

Punkte

Mutig tippen lohnt sich, daneben liegen kostet

Jeder Stich bringt Punkte, im späteren Spiel mehr. Für jeden Stich Abweichung vom Tipp gibt es 5 Punkte Abzug.

Spielen

Herunterladen oder selbst bauen

Windows

LumenX.exe · 64 Bit · ab Windows 10

Doppelklick genügt. Beim ersten Start meldet SmartScreen eine unbekannte App: „Weitere Informationen“, dann „Trotzdem ausführen“.

LumenX.exe laden

Linux

LumenX-x86_64.AppImage

Ausführbar machen und starten. Fehlt FUSE 2, startest du sie mit --appimage-extract-and-run.

chmod +x LumenX-x86_64.AppImage
./LumenX-x86_64.AppImage
AppImage laden

Aus dem Quellcode bauen

Du brauchst Rust (rustup). Für die Windows-Version zusätzlich den MinGW-Compiler.

# direkt starten
cargo run --release

# Linux-AppImage → LumenX-x86_64.AppImage
./build-appimage.sh

# Windows-.exe von Linux aus → dist/LumenX.exe
sudo apt install gcc-mingw-w64-x86-64
rustup target add x86_64-pc-windows-gnu
./build-windows.sh
