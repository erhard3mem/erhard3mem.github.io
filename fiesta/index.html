The ERP that runs on your own machine.

Fiesta is a lean ERP for small and medium-sized businesses: from request to quotation, order, delivery note and invoice in one fast desktop app. Your data stays in your own database: SQLite, PostgreSQL or Microsoft SQL Server.

New in version 0.10 · 18.10.2026

Notes, reminders and a calendar, right on the document.

  • Journal on every documentAdd notes and reminders to any quotation, order or invoice. Each user sees only their own entries, and the overview shows how many a document has.
  • Reminders that repeatOnce, daily, weekly, monthly or yearly, every n periods and until a date you choose. Marking one done moves it to the next date.
  • The bell in the header🔔 counts your due reminders. Mark them done or jump straight to the document.
  • Calendar in week, month and year viewYour own entries, all-day or with times, across several days if needed. Show your journal reminders alongside them, including every repetition.
  • Date pickerEvery date field now has a 📅 button with a month view.

Since version 0.9 · 18.10.2026

Run Fiesta on your company's database server.

  • PostgreSQL and Microsoft SQL ServerPoint Fiesta at an empty database. On the first connection it creates all tables, keys and the supplied document types, forms and sample queries.
  • Move your existing data“Transfer SQLite data” copies everything from your current file to the server: users, companies, documents, forms and the log. Document numbers continue where they left off.
  • Encrypted connectionsTLS off, if possible or required. Self-signed server certificates can be trusted explicitly.
  • Several workstationsWhen a colleague saves something, the Refresh button lights up on every other Fiesta that uses the same database.

Sample invoice

From line item to finished invoice.

Fiesta calculates as you type. Prices come from the customer's price group, and discounts and VAT appear instantly.

  1. Pick the customer

    Address and price group are taken from master data.

  2. Add items

    Choose the item number and enter a quantity. Fiesta fills in the description, unit and unit price.

  3. Apply a discount

    Per line, or as a document discount on the whole invoice.

  4. Print, mail or send as EDI

    The PDF uses your own form. Every change is logged with user and timestamp.

Releases

What changed since the video.

Fiesta is in active development. Each release extends the same database; existing data is migrated automatically.

  1. 0.1018.10.2026Journal and calendar. Notes and repeating reminders on every document, a bell for due reminders, week, month and year view. AI tasks are paused for now.
  2. 0.918.10.2026PostgreSQL and Microsoft SQL Server. Automatic setup, transfer of SQLite data, encrypted connections.
  3. 0.817.10.2026Print forms with Typst. Form editor with live preview, data fields, images and one form per document type.
  4. 0.716.10.2026Document types as data. Your own types with number ranges and follow-up rules; new delivery note.
  5. 0.616.10.2026AI tasks. Prompt scripts with tags for your data, run on Ollama. Paused since 0.10.
  6. 0.516.10.2026SQL editor and data model diagram. Terminal, memo fields, Refresh for several workstations.
  7. 0.416.10.2026Document chain, sales statistics, e-mail. Orders with partial quantities, paged overviews for large data sets.
  8. 0.315.10.2026Recycle bin, custom fields, EDI. Five languages and a Windows version. Shown in the video.
